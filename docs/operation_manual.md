# 成長型TODOリスト 操作マニュアル

## 1. 概要
このアプリは、TODOリストのタスクを完了させることで、サイトのデザインが豪華に進化していく「成長型」のアプリケーションです。

## 2. 操作方法
- **タスクの追加**: 入力欄にタスク内容を書き、「追加」ボタンを押します。
- **タスクの完了**: タスク横のチェックボックスをクリックします。
- **成長の仕組み**:
  - レベル0 (0個完了): 極めてシンプル
  - レベル1 (1-2個完了): 青色のアクセント
  - レベル2 (3-6個完了): 紫色のアクセントと影
  - レベル3 (7個以上完了): ピンク色の豪華なデザイン

## 3. 進捗の確認
画面上部に「現在のレベル」と「完了したタスク」が表示されます。タスクを増やすほど、使い心地が豪華になります。
